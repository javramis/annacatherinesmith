# annacatherinesmith

Website for actor Anna Catherine Smith. Plain HTML, CSS and JavaScript, hosted on GitHub Pages.

- `index.html`: all page text (bio, credits, press, contact)
- `js/main.js`: the video list (Vimeo IDs) and production photo groups
- `css/style.css`: colors, fonts, layout
- `images/`: web-sized photos
- `files/`: downloadable résumé
- `fonts/`: self-hosted Cormorant Garamond and Jost

All links are relative, so the site works at `javramis.github.io/annacatherinesmith` and on a custom domain.
